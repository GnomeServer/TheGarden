# Interactive calculator

A dependency-free browser calculator with 19 wired buttons, keyboard controls,
operator chaining, repeated equals, decimal input, and recovery from invalid
division or remainder.

Open `index.html` in a browser, or serve this directory with any static file
server. It has no backend and uses only `index.html`, `styles.css`, and
`calculator.js`.

Keyboard: digits, `+`, `-`, `*`, `/`, `%`, `.`, `Enter` or `=`, `Escape` or
`Delete`, and `Backspace`. `%` is the remainder operator.
